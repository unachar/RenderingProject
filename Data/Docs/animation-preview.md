# アニメーションプレビュー

メニューの「アニメーションプレビュー」、またはアニメーションモデルの Inspector にある「アニメーションをプレビュー・設定」から開く。

1. ヒエラルキーで対象を選び、「選択モデルを取り込む」を押す。モデルファイルを直接読み込んで確認することもできる。
2. 左の「アニメーションファイル」で VMD / FBX などを選び、「追加」を押す。既存クリップを選択して「選択クリップを付け替え」を押すと、その登録名のままファイルを変更できる。アセットブラウザからパス欄へのドロップにも対応する。
3. 再生・一時停止・先頭へ・速度・再生位置を操作し、右の独立プレビューで確認する。画像をドラッグすると回転、ホイールでズーム。「全体を表示」でカメラを戻す。
4. 「選択モデルに適用」で有効クリップと速度を適用し、先頭から再生する。適用先は同じモデルファイル・座標変換設定のアニメーションモデル。位置・回転・スケール・マテリアルは維持する。
5. シーンを保存する。適用操作は Undo / Redo に対応する。

VMD の身体と表情は複数選択して同時再生できる。同じボーンは下のクリップが優先される。FBX などは既存再生エンジンに合わせて単独選択となる。FBX 内蔵のモーションは、その FBX をアニメーションファイルとして追加できる。

ループ設定・シーク位置・カメラ操作はプレビュー専用。シーンへの適用はシーン再生停止中に行う。読み込み失敗時は既存プレビューとシーンを保持する。

プレビューではボーン・モーフと GPU スキニングを表示する。シーンの物理シミュレーションやタイムラインは実行しない。

## 検証

`scripts/test-animation-preview.ps1` で再生状態・クリップ選択・GPU フェンスに基づくリソース解放・旧クリップを除いた読み込み・シーン設定の JSON 往復と旧形式互換性を検証する。

Computer Use は使用していない。実画面での描画、ドラッグ・ズーム・シークの操作感、モデルごとのモーション・表情の適合、適用後の見た目と Undo / Redo は手動確認の対象。
