# ヒエラルキーとプレハブ

## 選択と編集

- ヒエラルキーの Ctrl+クリックで選択を追加・解除、Shift+クリックで表示中の行を範囲選択。Ctrl+Aで表示中の全行を選択。
- インスペクターの「選択対象を変更」でもチェックボックスで複数選択できる。
- 選択したオブジェクトの位置・回転・スケールをまとめて編集できる。最後に選択したオブジェクトを基準とし、ギズモも同じ選択に作用する。
- インスペクターの座標はワールド座標。複数選択での回転・拡縮は基準オブジェクトの位置を中心とする。
- 親と子を同時選択しても変形は一度だけ適用する。Deleteや削除ボタンでは子階層も削除する。Ctrl+Z / Ctrl+Yで操作単位の取り消し・やり直しができる。

## 親子関係

ヒエラルキーでオブジェクトを別のオブジェクトへドラッグするか、インスペクターの「親」を指定する。親を変えてもワールドでの配置は保つ。「親: なし（ルート）」、右クリックの「親を解除」、ツリー末尾へのドロップで解除できる。

「+ 作成 → 空のオブジェクト」で整理用の親を作成できる。循環する親子関係は拒否する。親子関係はシーン保存に含まれる。

## プレハブ

1. ルートを選び、インスペクターの「選択からプレハブを作成」を押す。子階層も含め、現在のアセットフォルダーへ `.prefab` を作る。ヒエラルキーからアセットフォルダーへのドロップでも作成できる。
2. アセットのダブルクリックで配置、シーンビューへのドラッグでその場所へ配置する。
3. 「プレハブに適用」は元アセットと同じシーン内の全インスタンスを更新する。インスタンスのワールド位置・回転・スケール・親を保持し、同じプレハブ内IDのオブジェクトはエンティティIDも保持する。
4. 「元に戻す」で元アセットの内容を読み直す。「プレハブのリンクを解除」で通常のオブジェクト階層にする。

プレハブのキューブアイコン、アセット名、ヒエラルキー、インスペクターは水色で表示する。シーン保存にはプレハブへのリンクと内部IDも含まれる。

この実装では個別プロパティのオーバーライド追跡やプレハブVariantは扱わない。「適用」「元に戻す」は配置以外のインスタンス編集も元アセットへ揃える。元アセットへの書き込みはシーンのUndoとは別で、シーンのUndoはインスタンスの状態を復元する。

## 検証

- `scripts/test-entity-hierarchy.ps1`: 循環・選択ルート・子階層・行列変換・非均等スケール・更新順序のテスト。
- `scripts/test-prefabs.ps1`: プレハブ形式、ID重複、存在しない親、循環、不正ルートのテスト。
- `scripts/validate-editor-objects.ps1`: Release実行ファイルを起動して親子の一括変形、Undo/Redo、プレハブ配置・適用・復元、削除Undoを検証する。一時プレハブは終了時に削除する。
