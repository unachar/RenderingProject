# オーディオアセットと再生エンジン

## 方式

公式リリースで固定した miniaudio を使い、Windows の再生デバイス、デコード、3D 音源、バス、PCM フレーム単位の開始予約を共通化する。既存の Dear ImGui エディター内にオーディオアセットの編集画面を作り、Asset Browser、シーン、Sequencer から参照する。[miniaudio 公式マニュアル](https://miniaud.io/docs/manual/index.html)

FMOD Studio を使う方式ならイベントやミックスの編集機能を利用できる。今回は既存エディターで波形を編集し、同じ設定をシーンと Sequencer の両方に配置する体験を優先する。DirectXTK の AudioEngine は XAudio2 上で 3D 音源を扱えるが、今回の共通デコードと再生予約には追加の実装が要る。[FMOD Studio](https://www.fmod.com/docs/2.03/studio/authoring-events.html) · [DirectXTK Audio](https://github.com/microsoft/DirectXTK/wiki/Audio)

## データと編集

- オーディオアセットは既存のアセットルート相対パスで音声素材を参照する。原音を保ったまま、トリムとループ区間、フェード、ゲイン、ピッチ、バス、2D/3D、距離減衰を保存する。クリップと音源はアセットを参照し、個別の音量と位置を持てる。
- オーディオエディターは波形、再生カーソル、区間マーカー、詳細設定を一画面に出す。波形は既存の非同期キャッシュを共通デコーダーに接続し、ステレオの左右を表示する。波形で区間を動かし、数値入力で微調整し、変更を試聴できる。長尺音源も分割読込し、読込中と破損・欠落を区別する。
- Master 配下に Music、SFX、Ambience、Voice のバスを置く。音量、ミュート、ソロと出力ピークを確認できる。バスの低域・高域 EQ とクリップ音量のオートメーションを編集・保存し、試聴と実行時の両方に反映する。試聴は編集画面から明示的に始め、停止・画面終了で解放する。
- Asset Browser からシーンへ配置すると、既存 Transform を持つ音源を作成する。Inspector で参照、Play on Awake、ループ、距離減衰を調整する。手動再生には Sequencer とランタイムから呼べる再生・停止 API を使う。カメラをリスナーとし、階層を反映したワールド座標を使う。タイムライン用の 3D 音はシーン座標を指定するか音源エンティティに追従させる。
- Sequencer に複数の音声レーンを追加する。アセットをドロップした時刻にクリップを作り、ドラッグと数値入力で位置と長さを調整する。重なったクリップは同時再生する。クリップと音源は既存のシーン・Prefab の保存と参照解決に統合する。

## 再生と互換性

- デバイスとミックスを共用し、試聴、シーン音源、BGM、タイムラインのボイスはそれぞれの所有者が管理する。WAV・MP3・FLAC を共通デコーダーで扱う。長尺 BGM はストリーミングし、短い効果音は再生前に準備する。失敗を該当アセットやクリップへ返し、他の音源とタイムラインを継続できるようにする。
- 既存シーンの `music`、`musicOffset`、`musicVolume` とテンポ設定を読み込む。BGM 付きタイムラインは曲の再生位置から従来の演出時刻を導き、Audio Spectrum は同じ素材の独立したデコード経路から PCM を読む。BGM のないタイムラインは既存の時刻進行を維持する。
- 通常の正方向再生では、次のクリップをミックス時計へ先行予約する。停止、一時停止、シーク、ループ境界、編集、プレイセッション変更で古い予約を破棄する。シーク先に重なる持続音は該当オフセットから再生を再構成し、通過したワンショットは発火しない。BGM のないタイムラインで再生速度を変える場合も、クリップの開始・終了時刻はタイムライン速度に従い、音程はアセット側の設定に従う。逆再生は視覚評価を行い、正方向に戻った時点で予約を再構成する。

## 受け入れ確認

Windows ビルドと既存の音楽クロック・タイムラインテストを実行する。実機で既存シーンを開き、BGM の一時停止・シーク・ループと演出同期を確認する。素材をオーディオアセットとして保存して再度開き、波形編集、トリム、フェード、バスとループが試聴に反映されることを確認する。同じアセットをシーンに置いてカメラ移動による定位・減衰を確認し、Sequencer では任意の時刻への配置、同時再生、ループとシークを確認する。保存したシーンと Prefab を再読込し、音源とクリップの設定・参照が戻ることを確認する。
