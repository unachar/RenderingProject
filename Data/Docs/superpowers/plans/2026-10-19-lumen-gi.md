# Lumen方式GI Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 既存GIを保持して、DXRによる表面キャッシュとプローブギャザーを追加し、更新予算で負荷を制限する。
**Architecture:** 永続メッシュIDをキーに6方向のカードを割り当てる。GPUで境界と材質をキャプチャし、前回確定した照明から多重反射を更新する。画面プローブをフル解像度へ再構成して既存の合成へ渡す。
**Tech Stack:** C++17、DirectX 12、HLSL cs_6_5、既存DXR/NRD。
**Spec:** docs/lumen-integration-design.md

## Global Constraints

- DXR Tier 1.1を使用。メッシュSDF・透過GIは対象外。
- Off/ScreenSpace/Realtimeの保存値を保持する。
- キャッシュの読み書きを分離し、未対応面は既存ヒット評価へ戻す。
- 放射照度を出力し、受光側の反射率/piは一度だけ適用する。
- エディター設定を検証後に復元する。既存モードのGPU検証を維持する。

## Review Focus

- メッシュ順の変更や所有者削除で別メッシュのカードを参照しない。
- 薄壁とカードの裏面を深度・法線で棄却する。
- 静止カメラでの照明変更を検出する。
- NRDなし、奇数解像度、リサイズでも全出力を定義する。
- 更新予算を超える面はフォールバックし、不正な古い光を使わない。

## Task 1: カード所有と更新予算

**Files:** source/rendering/lumenscheduler.h, tests/lumenscheduler_tests.cpp, scripts/test-lumen.ps1, source/rendering/raytracingscene.h/.cpp
**Interfaces:** Scheduler::Prepare(inputs, captureBudget, lightingBudget)が安定したスロット割当、キャプチャ一覧、照明更新一覧、インスタンス対応を返す。入力は所有者ID、材質・形状署名、距離。

- [ ] 所有者の並べ替え・削除・再利用・予算上限・飢餓防止・変更時の再キャプチャのCPUテストを先に作り、失敗を確認する。
- [ ] スケジューラーと永続メッシュIDを実装し、CPUテストを通す。

## Task 2: GPU表面キャッシュと照明

**Files:** source/rendering/lumensurfacecache.h/.cpp, shader/hlsl/LumenSurfaceCache.hlsli, source/rendering/rayreflections.cpp, DirectX12.vcxproj
**Interfaces:** キャッシュ管理はGPUリソース・フレーム別アップロード・SRV/UAVを所有する。rayreflectionsの既存シーン/材質バインドを共有する。

- [ ] カード境界、深度・法線棄却、表裏、無効面を検証するテストを追加する。
- [ ] 6方向のGPUキャプチャ、材質アトラス、読み書き別照明、変更無効化を実装する。
- [ ] キャプチャは変更面のみ、照明は予算内のラウンドロビン更新とする。
- [ ] シェーダーをNRDあり/なしでコンパイルし、GPUでカバレッジと編集反映を確認する。

## Task 3: プローブギャザーと反射

**Files:** shader/hlsl/LumenGather.hlsli, shader/hlsl/RayReflectionsCS.hlsl, source/rendering/rayreflections.cpp
**Interfaces:** 低解像度プローブの位置/法線/方向別信号を全解像度の既存GI入力へ再構成する。反射は同じキャッシュの間接光を使う。

- [ ] 画面外発光・遮蔽物・二次反射・反射内GIをGPU検証へ追加する。
- [ ] プローブをトレースし、深度・法線・接続可視性を考慮して再構成する。
- [ ] 不適合プローブの面には既存トレースを使う。ReSTIRのピクセル契約をプローブへ流用しない。
- [ ] 奇数解像度、カメラカット、モード切替、NRDなしを検証する。

## Task 4: エディターとモード統合

**Files:** source/rendering/renderersettings.h, source/editor/editorsettings.cpp, source/rendering/performancegovernor.h

- [ ] 新モードの保存/読込・既存モード値・設定境界を確認する。
- [ ] 更新予算、プローブ間隔、診断表示を接続する。
- [ ] 非対応GPUとリソース作成失敗の状態を明示する。

## Task 5: 性能測定と回帰確認

**Files:** scripts/validate-gi.ps1, source/core/givalidation.cpp, docs/lumen-integration-validation.md

- [ ] 同一シーンで既存GI/新GI/更新予算変更を比較し、CPU/GPU時間、レイ数、VRAM、更新遅延、画像差を記録する。
- [ ] Debug/Release、NRD有無、既存GI回帰、時間安定性を検証する。
- [ ] 差分を独立レビューし、重要な指摘を修正・再検証する。測定していない性能改善は主張しない。
