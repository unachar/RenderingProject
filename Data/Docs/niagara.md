# Niagaraエフェクト

このエンジン専用の `.naiagara` アセットでエフェクトを編集する。UEのアセットファイルの読み込みには対応しない。

## 使い方

1. アセットブラウザーで右クリックし、作成メニューの「Niagaraシステム」を選ぶ。
2. `.naiagara` をダブルクリックする。ウィンドウメニューの「Niagara」からも開ける。
3. 中央のシステム概要でエミッターまたはモジュールを選び、右側で設定する。エミッターカードはキャンバス上で移動できる。
4. 左側でプレビューと公開パラメーターを調整する。左ドラッグで回転、中ドラッグでパン、ホイールでズーム。背景、地面グリッド、全体表示も変更できる。
5. 下部で再生、一時停止、先頭、前後フレーム、ループ、速度、長さを変更する。目盛りをドラッグしてシークする。区間をドラッグして移動し、両端をドラッグしてエミッターの開始・終了を変更する。目盛り上のホイールはズーム、中ドラッグは表示範囲移動。
6. 「保存」またはCtrl+Sで保存する。「別名で保存」はCtrl+Shift+S。Ctrl+Z、Ctrl+Shift+Z／Ctrl+Yで編集を戻す・やり直す。
7. 保存後に「シーンへ配置」を押す。アセットをシーンへドラッグする操作にも対応する。配置したエンティティのNiagaraセクションで自動再生、速度、ループ上書き、エディター内プレビューを変更する。配置と設定はシーンのUndoと保存に含まれる。

未保存でアセットを切り替える、ウィンドウを閉じる、アプリを終了する場合は保存・破棄・キャンセルを選択できる。読込や検証に失敗した場合は診断を表示し、最後に有効だった編集・実行状態を保持する。

## モジュールグラフ

「Custom Graph」を追加して選び、中央の「モジュールグラフ」タブで編集する。ノードは既存マテリアルのデータモデル、定数・演算、型検査、ノード編集ライブラリを共有する。「選択ノードを出力に」で結果を選び、右側で書き込み先を指定する。表面シェーダーだけで意味を持つノードは候補へ出さない。

Particle Spawn／Updateでは位置、速度、色、サイズ、寿命へ書き込める。寿命の書き込みはSpawnに限定する。System Spawn／UpdateはSystemスコープ、Emitter Spawn／UpdateはEmitterスコープの既存パラメーターへ書き込む。Emitterスコープの実行値はインスタンス内のエミッターごとに分離される。

パラメーター参照ノードの名前を公開パラメーター名に一致させる。Scalar Parameter、Vector2 Parameter、Vector Parameter、Color Parameterはそれぞれ1、2、3、4成分を参照する。`Particles.Position`、`Particles.Velocity`、`Particles.Color`、`Particles.Age`、`Particles.NormalizedAge`、`Particles.Size`、`Particles.Lifetime` は粒子属性の参照名。Timeはシステムの経過秒、World Positionは粒子のシミュレーション空間の位置になる。

## 対応範囲

| 項目 | 現在の実装 |
| --- | --- |
| シミュレーション | 1/60秒の固定刻み、シード付き乱数、予算付きシーク再計算、複数エミッター、ローカル／ワールド空間 |
| 発生・初期化 | 連続発生、バースト、初期色・寿命・サイズ・球状発生範囲、初速度とランダム幅 |
| 更新 | 加速度、抵抗、揺らぎ、寿命に沿った色・サイズ、キー補間、地面との衝突 |
| イベント | 死亡イベントから別エミッターへ発生 |
| レンダラー | 柔らかい円形スプライト、内蔵キューブメッシュ、エミッターごとのリボン。混在プリミティブを深度で並べる |
| 保存 | バージョン付きJSON、グラフ・カーブ・カード位置、原子的な置換、破損・上限検証 |
| シーン | アセット参照、配置・複製・削除、シーン／Prefab保存、実行インスタンスの分離、再読込 |
| GPU | DX12 Computeによる粒子更新とカスタムグラフ。パラメーターは実行時バッファで渡す |

GPUは各ステップで結果をCPUへ読み戻す同期型の参照実装で、大量粒子向けの非同期実行・性能最適化は未実施。CPUとGPUのビット単位の一致は保証しない。決定的な再評価は同一バックエンド・シード・入力・固定刻みの範囲とする。

外部メッシュや任意のパーティクルマテリアル／テクスチャの指定、汎用のEvent／Renderカスタムグラフ、任意の可変な粒子独自属性、UE固有のデータインターフェースは未対応。Particlesスコープのユーザー定義パラメーターは入力の既定値であり、粒子ごとの可変ストレージではない。Niagaraの全機能互換として扱わない。

## UI更新（2026-11-06）

UE Niagaraの参考画像に合わせ、システム概要はプレビュー・パラメーター・キャンバス・選択詳細を横に配置。右の選択詳細は全高を使い、左側の下部でタイムライン・カーブ・Niagaraログを切り替える。モジュールグラフではパラメーター列をスクリプト詳細・パラメーター・統計に切り替え、プレビューは常に表示する。画像の黄色い枠と番号は解説用の注釈として扱い、UIには追加していない。

マテリアルと共通の `graphvisuals.h` でカテゴリ別ヘッダー色、型別ピン色、成分色、未接続の中抜き／接続済みの塗りつぶしを共有。入力は左、通常出力は右上に配置する。接続線も出力の型に合わせて着色。ピンの右クリックで出力指定、分割・統合、接続解除ができる。未接続の入力値を直接編集できる。

最終Release x64ビルド成功（6.986秒）。記録: `build/build-performance/Release-Build-20261106-085030.json`。新規テストコードは追加していない。

## ウィンドウ操作・範囲表示の更新

タイトル右端に最小化（タイトルのみへ折り畳み）・展開、最大化・元のサイズへ復元を追加。最大化はアプリの作業領域に追従する。プレビューは概要／カスタムグラフの両方で常時表示し、左ドラッグで回転、中ドラッグでパン、ホイールでズームする。ドラッグ中はプレビューが入力を保持し、親ウィンドウの移動へ渡さない。

シーンに配置・選択したNiagaraの推定範囲を、オレンジ色の立体グリッドで表示する。寿命・初速度・ランダム幅・加速度・初期サイズなどから保守的に推定し、現在の粒子が外へ出た場合はその位置も含める。Transform、ローカル／ワールド空間を反映し、範囲グリッドはInspectorで表示を切り替えられる。エディター専用でゲーム再生には表示しない。カスタムグラフの任意の将来の移動を保証する固定Boundsではない。

Release x64ビルド成功（8.258秒）。記録: `build/build-performance/Release-Build-20261106-090854.json`。新規テストコードは追加していない。

実画面で最大化／元のサイズへの復元、最小化／展開、左ドラッグでの視点回転（ウィンドウ位置が変わらないこと）、既存カスタムグラフ編集時のプレビュー表示、シーン配置直後の範囲表示を確認。確認用のシーン配置はUndoで取り消し、シーンとNiagaraアセットは保存していない。DPI変更、複数モニター、カスタムグラフによる任意の範囲変化は未検証。
