# LiveDirector・ステージ制御

エンティティのTimelineから、曲、ダンス、カメラ、ライト、発光メッシュを制御する。
`asset/Scenes/LiveStage.scene` は既存アセットを使った16秒ループのサンプル。
`asset/Prefabs/LiveStage.prefab` は同じ構成をまとめたPrefab。

## 再生と同期

- 曲を指定すると、既存の `LiveMusic::XAudioMusicPlayer` のサンプル時刻をTimelineの基準にする。対応形式はPCM16 / IEEE float32 WAV。未指定時は従来のフレーム時刻で動く。
- 「曲の開始位置」は音声の冒頭をスキップする秒数。Timelineの0秒に、その音声位置を対応させる。
- エディター上部のPlayで開始する。Timelineの停止、一時停止、再生ヘッド変更、エディター全体の停止・一時停止に音声も追従する。
- 曲がTimelineより短い場合は曲末尾で停止またはループする。曲ありの再生速度は1倍。
- BPM・先頭ビートでステージライトの周期を設定する。ビート位置は既存の `LiveMusic::TempoMap` を使って求める。
- 再生停止時は開始前のTransform、アニメーション、ライト、マテリアル、Bloom、局所Fogを復元する。

XAudio2の消費サンプル位置はスピーカーから実際に聞こえた時刻ではない。機器の出力遅延を含む厳密な音映像同期の校正は別途必要。

## キーフレーム

既存のTransform・Cameraに加え、LightのIntensity / Color / Direction / Range / Beam Density、BloomのThreshold / Soft Knee / Radius、FogのDensity / Color、AnimationのTime、MaterialのEmissive Intensity / Colorを選べる。

ダンスやカメラVMDを曲と同期させるには、対象にAnimation / Timeトラックを追加し、例えば0秒→0秒、16秒→16秒のキーを置く。アニメーションは対象にあらかじめ読み込む。カメラVMDがないカメラはTransform・Cameraトラックで制御できる。

Fogは環境設定の局所Fog一覧に対する `Fog Volume Index` を指定する。対象ボリュームを先に作成する。Fog一覧の並べ替え・削除後はインデックスを見直す。

発光制御・モニターには専用メッシュを使う。アセットマテリアルが割り当てられた対象では、その先頭マテリアルをエンティティ固有の実行時設定へ展開する。共有マテリアルアセットは書き換えない。複数マテリアルの部位別制御には対応していない。

## ムービングライト

Timeline内の「ステージライト」から4灯Spotを作成できる。灯体はTimelineの子になり、グループに参照が登録される。Pan・Tiltと振幅、拍単位の首振り周期、各灯体の位相、2色の切替、ストロボ回数・点灯比率、ビーム密度を編集する。

絶対時刻から状態を計算するため、シークしても途中のビートイベントを再実行する必要はない。灯体ごとのLightトラックはグループ設定の後に適用され、その項目を上書きする。グループ削除は設定だけを削除し、子の灯体は残す。

ルートを既存のPrefab作成操作で保存すると、灯体・グループ設定・参照をまとめて再利用できる。Scene / Prefabの参照リマップは既存の共通Archiveを使う。

## LEDモニター・発光床

Timeline内の「LEDモニター・発光床」で発光メッシュと周辺照明用のRectライトを指定する。「画像をここにドロップ」へプロジェクト内の画像・複数画像・フォルダー、またはエクスプローラーの画像をドロップすると末尾へ追加する。クリックして画像を選ぶこともできる。PNG / JPG / JPEG / DDS / BMP / TGAに対応する。

登録画像はサムネイルで表示し、サムネイル同士のドラッグで順序変更、各画像の「削除」で取り除ける。表示順はこの一覧の順番。フォルダー・複数アセットの一括追加時はファイル名順に並ぶため、連番名は `0001.png` のように桁を揃える。FPS・開始秒・ループ・発光強度も同じ画面で設定する。1枚なら静止画になる。外部画像は元のファイルを参照するため、プロジェクトと一緒に管理する場合は先にasset内へ置く。

LED板に使うCubeのUVは、外側から画像が正しく読める向きに修正した。サムネイル用や元の画像ファイルを反転して補正する必要はない。

同じ画像をメッシュの発光テクスチャとRectライトの発光面に使う。Rectテクスチャ照明は既存のMegaLights経路を利用するため、その描画設定を有効にする。動画ファイルのデコードには対応していない。大きな連番の読み込み・GPUメモリー使用量には注意する。

### 停止後の速度履歴

姿勢キャッシュでGPUスキニングを省略したフレームに、前回の移動前の頂点が残り続ける問題を修正した。姿勢が変わったフレームの全描画パスでは履歴を保持し、次の姿勢固定フレームに一度だけ現在頂点を履歴へコピーする。停止後の変形速度がゼロになり、モーションブラーや時間再投影が古い変形を参照し続けない。

シーク・ループ・全体停止ではカメラカットも通知し、連続再生用の描画履歴をそのまま持ち越さない。`build/live-director-motion-history-build.log` のRelease x64ビルド・リンク成功と、モーションブラーONでの再生→8.298秒シーク→時刻固定の描画を確認した。固定後に前回の点状の欠けは観察されなかった。

前回の保存設定はモーションブラーOFFだったため、元の点状ノイズをブラーだけの問題とは断定していない。サンプルのテクスチャ指定漏れも修正しており、両変更を含む状態での確認結果。

履歴判定には、プロファイラーの有効状態に依存しないTemporalHistoryの描画フレーム番号を使う。最終ビルドで計測OFF・モーションブラーONの再生→一時停止→全体停止も確認し、点状の欠けは観察されなかった。
