# DXC-only Shader Compilation Implementation Plan

> **For agentic workers:** Use the current parallel tasks for independent test and runtime changes; execute build integration in this chat.

**Goal:** Compile every project and test shader with DXC, with no FXC fallback.

**Architecture:** Keep the existing DXC NuGet package and runtime compiler wrapper. Route Visual Studio HLSL items to dxc.exe and Shader Model 6, and migrate legacy D3D11 GPU fixtures to D3D12 so they can execute DXIL.

**Tech Stack:** MSBuild, DXC 1.9.2602.24, HLSL, C++, Direct3D 12.

**Spec:** User request in this chat: retire FXC and use DXC for all future compilation.

## Global Constraints

- Preserve shader entry points, output paths, material behavior, and existing GPU assertions.
- Blob creation/loading through d3dcompiler.lib may remain; shader compilation must use DXC.
- Report unavailable or failed runtime validation accurately.

## Review Focus

- Debug and Release must both invoke the bundled dxc.exe.
- Win32 metadata must not fall back to an Effect/SM5 profile.
- Shader include edits must remain tracked by incremental compilation.
- Runtime compilation must have no conditional legacy fallback.
- GPU fixtures must execute DXIL using D3D12 and retain their numeric checks.

## Validation results

- Debug x64 full build passed in a normal Windows permission context with the original C++ Debug settings.
- All four project configurations passed compiler/profile/stage checks; all 77 tracked shader outputs contain DXIL.
- Shader dependency tracking, persistent cache, and embedded ImGui shader compilation checks passed.
- Camera projection and Hi-Z GPU checks passed. Temporal tests passed 17 scenarios and 336 direct/tiled comparisons.
- Focused code review found no actionable issues.
- Procedural GPU parity remains unsuccessful: the hardware run reports White noise (`basis=4`, `fractal=0`) maximum error `0.737312`; the WARP run terminated abnormally. These runtime results are not reported as passing.

The migration also specifies HLSL 2018 mode for the two AMD FSR SDK wrappers and uses componentwise `select` in the two project shaders that previously relied on legacy vector ternaries. ImGui's embedded shaders compile through DXC rather than the legacy compiler.
