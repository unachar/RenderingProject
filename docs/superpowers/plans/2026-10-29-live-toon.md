# Live Toon Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Add readable live-stage cel lighting and remove unnecessary outline work.

**Architecture:** Share per-light toon math between Forward and Deferred through
SurfaceLighting. Preserve material/constant-buffer layouts. Track requested TEO
presets independently of the base-pose skinning cache.

**Tech Stack:** C++17, HLSL, DirectX 12, DXC, portable C++ tests.

**Spec:** docs/superpowers/specs/2026-10-29-live-toon-design.md

## Global Constraints
- Work on dev_main; preserve existing Extrude/TEO/Mix and four presets.
- No new asset dependencies or constant-buffer layout changes.
- No claim of measured GPU speedup without runtime measurements.

## Review Focus
- Opposing and black lights retain valid finite contributions.
- Base color and shadow visibility must each be applied once.
- Skin shading must retain color while cloth responds to stage tint.
- Zero-width outlines and zero-normal TEO anchors must stay fixed.
- Mode changes at the same pose and multiple users of one model must remain valid.
