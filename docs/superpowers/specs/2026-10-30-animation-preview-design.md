# アニメーションプレビューとシーンモデルへの適用

## 目的

Karen / XBot などのアニメーションを、C++ の Create を編集せずに読み込み・付け替え・再生確認できるようにする。保存シーンから復元されたモデルにも UI から適用できること。

## 採用する構成

独立した ImGui の「アニメーションプレビュー」ウィンドウを追加する。ProceduralStudioWindow の幅変更可能な2列レイアウトに倣い、左に設定、右にモデルプレビューを配置する。適用先はユーザーが選択した「選択中のシーンモデル」とする。

シーン内モデルを直接再生して確認する方式は、試している途中の変更がシーンへ混ざるため採用しない。既存 Inspector だけを拡張する方式も、要求された独立プレビューの配置に合わないため採用しない。

## 左側の設定

- 選択中のアニメーションモデルをプレビュー対象として取り込む。モデルファイルから対象を読み込む操作も用意する。
- アニメーションファイルを参照・読み込みできる。対象は既存ローダーが対応する VMD / FBX などとし、非対応・失敗を画面に表示する。
- 登録済みクリップを選択し、追加・差し替え・削除を行う。Karen の身体と表情のような複数クリップの同時再生にも対応する。
- 再生・一時停止・先頭へ戻す・速度・ループ・再生位置の操作を用意する。
- 適用対象の名前を表示し、「選択モデルに適用」を押した時だけ設定を反映する。未選択・非対応モデル・読み込み未完了・再生中のシーンへの適用は無効にし、理由を表示する。

## 右側のプレビュー

- シーンに登録しない独立モデルと描画先を使用する。プレビューは実際のスキニング結果を表示する。
- マウスで回転・ズームし、全体表示へ戻せる。
- 停止中もシーク結果が表示される。閉じている間は更新を止める。
- シーン側と可変ポーズ・GPU バッファを共有しない。切り替え・終了時に GPU の使用期間を守ってリソースを解放する。

## 適用と保存

適用では対象の位置・回転・スケール・マテリアルを維持し、アニメーションのパス・登録名・再生選択・速度を更新する。モデルを別ファイルに置き換える操作はこの適用ボタンに含めない。プレビューと適用対象のモデルが異なる場合は適用を無効にし、選択モデルを取り込むよう案内する。

適用は既存の Undo / Redo とシーン変更検知へ統合する。シーンを保存して開き直すと設定を復元できる。プレビューだけの操作はシーンを変更しない。

## 実装・検証

既存の AnimationModelResource / Animator / CreateAnimModelInstance とシーンのアニメーション保存形式を再利用する。描画は既存のプレビュー用描画資産を調査して共通利用できる部分を使い、アニメーション専用の責務は別ファイルへ分ける。

クリップ設定変更・失敗時の保持・複数クリップ・再生位置などの状態処理を対象に必要なテストを追加し、C++ ビルドを確認する。画面操作の確認はユーザーが行うため Computer Use は使わず、未確認の描画・操作項目は最終報告に明記する。
