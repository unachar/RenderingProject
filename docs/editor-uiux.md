# Dear ImGui エディターのUI・UX改善

実施日: 2026-10-06。対象はDirectX12＋Dear ImGuiの既存エディター。
UI UX Designerの情報階層、状態表示、操作の発見しやすさ、誤操作防止の指針を適用した。

## 画面構成と操作

- 初期配置は左にヒエラルキー、中央にシーン、右にインスペクター／レンダーコントロール、下にプロジェクト／ログ。既存の保存済み配置は維持する。
- 「ウィンドウ → 標準レイアウトに戻す」で配置を復元する。ヒエラルキーとインスペクターを個別に開閉できる。
- シーン上部に移動・回転・スケールとライト可視化を配置。映像を縦横比を保って中央配置し、操作説明の表示領域を確保する。
- ヒエラルキー、アセット、ログに検索とクリアボタンを追加。カンマで複数の候補、`-語句`で除外を指定する。除外条件は記入順に関係なく優先する。
- ヒエラルキーの右クリックから名前変更・削除。F2で名前入力にフォーカスし、Enterで確定、Escapeで取り消す。
- アセットはクリックで選択、ダブルクリックでフォルダを開く／テクスチャを適用。作成欄を「+ 作成」にまとめて一覧を広げる。削除前には対象パスと取り消せない旨を表示する。
- ログに「末尾を追従」を追加。過去のログを閲覧している間は自動的に末尾に戻さない。
- 編集メニューに元に戻す／やり直しを集約。再生・停止・一時停止・再開と動作状態を日本語で表示し、停止ボタンは赤系にする。
- 文字入力中はエディターのUndo/Redoを呼ばず、入力欄の編集を優先する。Deleteによるオブジェクト削除はシーン／ヒエラルキーにフォーカスがある場合に限定し、アセット削除と競合させない。
- 未選択・検索結果なし・フォルダ読込エラーに説明を表示。補助文字のコントラスト、余白、スクロールバーと操作ハンドルのサイズを調整する。

## 検証結果

- x64 Debugのコンパイル・リンク成功。通常の`/ZI`ではこの環境のPDB生成でC1902が発生するため、検証プロセスのみ`_CL_=/Z7`を設定した。プロジェクトのビルド設定は今回変更していない。
- `tests/run_editor_ui_tests.py`成功。実際のDockSpace、スタイル、検索ウィジェットの関数本体を抽出し、同梱Dear ImGuiとコンパイルして実行する。初期配置、ユーザー配置の維持、配置復元、800×600への変更、検索除外条件、クリアボタンのクリックを確認した。
- 変更したエディターファイルの`git diff --check`成功。
- 既存の`check_project_structure.py`は`source/scene/Camera.cpp`・`Camera.h`とプロジェクト登録の`camera.cpp`・`camera.h`の大文字小文字の差で失敗する。今回の変更による登録追加・削除はない。
- 実GPUでの描画、実画面の視認性、エディター全機能の操作は未確認。ヘッドレステストはこれらを代替しない。

再実行はVisual Studio x64 Developer Command Promptで行う。

```bat
python tests\run_editor_ui_tests.py
set "_CL_=/Z7"
MSBuild DirectX12.sln /t:Build /p:Configuration=Debug /p:Platform=x64 /m
```

## 実画面の確認手順

1. 起動後、保存された配置が維持されることを確認。「ウィンドウ → 標準レイアウトに戻す」で標準配置へ戻す。
2. シーンのツールボタンとQ/W/Eを切り替え、ギズモの位置が映像に合うこと、余白部分が選択対象にならないこと、カメラ操作とD&D配置が動くことを確認する。
3. ヒエラルキーで検索、検索クリア、F2、Enter、Escape、右クリックを確認。検索中にQ/W/EやCtrl+Zを入力してもシーン操作に影響しないことを確認する。
4. アセットのクリックが選択だけを行い、ダブルクリックが開く／適用を行うことを確認。Deleteと右クリック削除の両方で確認ダイアログが出ること、キャンセルでファイルもオブジェクトも消えないことを確認する。
5. ヒエラルキーだけを閉じてもインスペクターが残ること、両方をメニューから開けることを確認する。
6. ログを検索してクリア。追従を無効にした状態と、追従を有効にして上へスクロールした状態で、新着ログが閲覧位置を奪わないことを確認する。
7. 再生・一時停止・再開・停止、800×600程度への縮小でボタンと入力欄を操作できることを確認する。
