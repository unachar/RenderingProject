# 夕焼けと仮想月の照明

`CelestialLighting.hlsli` は球状大気のRayleigh/Mie減衰と仮想満月を共有する。雲に入る太陽光は雲層の上下で大気透過率を計算して高さで補間し、低い太陽から届く光を赤橙色にする。太陽の有効状態、色と強度は既存の選択されたSunに従う。環境光は昼・夕暮れ・夜で変化する。

仮想月は太陽の反対側を回る満月固定の近似で、物理空が有効なときに地平線上へ出ると照明する。月円盤とハローは空に描き、既存の雲合成で隠れる。雲内部では月方向への密度積分によって自己陰影をつける。DeferredのPBR材質には同じ月方向からdiffuse/specular照明を加え、Cloud shadowsが有効な場合は雲による減衰を反映する。

天文暦・月相・月専用の建物などのシャドウマップ・Forward材質の月照明は未対応。光量は既存レンダラーに合わせた値で、写真の露出や実測照度を再現する較正ではない。

`scripts/validate-clouds.ps1` は既存の雲回帰検証に加え、夕暮れと深夜の有限・非負散乱を確認し、`cloud-sunset.png` と `cloud-moon.png` を保存する。
