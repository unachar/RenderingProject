# Stage 2 J — Local reflection probes: design

Implements expansion feature J (Phase 2 J in
`rendering-expansion-progress.md`): local reflection probes with
box projection and blending, as the reflection fallback when DXR
reflections are unavailable.

## What the engine already does

Image-based lighting samples one global equirectangular
`EnvironmentTexture` (a loaded HDR DDS, `m_EnvironmentTextureSrvIndex`)
in `SurfaceLighting.hlsli`: specular at mip `roughness * 8`,
irradiance at the last mip. Passes bind that SRV index when they set
up lighting. There is no cubemap capture or probe infrastructure.

## v1 design (staged, like 1C/1D)

- A **ReflectionProbeComponent** (entity transform = probe position)
  carries an influence box (full extents), an environment texture
  path (equirect HDR, prefiltered mips included — the same contract
  as the global environment texture), a priority, and an intensity.
- Each frame, the probe system selects the **active probe**: the
  highest-priority probe whose influence box contains the camera
  (ties: nearest center). When one is active and the flag is on,
  passes bind the probe's SRV index instead of the global
  environment index. This is a deliberate v1 simplification: no
  shader changes, no per-pixel blending yet; the swap is global for
  the frame, which is exact when the camera is inside one dominant
  probe volume.
- **GGX prefilter**: probes whose source texture has no mip chain
  get one generated by a compute prefilter (importance-sampled GGX
  over the equirect source, 9 levels to match `roughness * 8`), so
  authored single-mip HDR images work as probe sources.
- Later stages (not v1): live cubemap capture of the scene, box
  projection parallax correction and per-pixel two-probe blending
  inside the lighting shader, probe relocation/baking in the editor.

## Gating

`RendererSettings::UseLocalReflectionProbes` (default OFF). With
the flag off the override is always cleared and the global
environment texture is used exactly as before.

## Acceptance (from the ledger)

Parallax/boundary behavior at box edges, roughness response across
mips, transitions when moving between probes and to the global
environment, DXR on/off consistency, save/load of probe components,
capture/prefilter timing.
