# ライブ向けセルシェーディングと輪郭線

Hair / Cloth / Skin / Toon（分類1〜4）をForward・Deferredの両方で照明する。
自動分類の髪・衣装・肌がDeferredで未照明になっていた経路も対象。
ライトごとに段階陰影、ハイライト、逆光リムを計算するので、左右の色付き
ライトの方向が平均化で打ち消されない。肌は照明色の一部を輝度に置き換えて
色を保ち、衣装・髪は照明の色を強く受ける。露出・BloomのためHDR値を保持する。
ベースカラーとライト強度、距離減衰、影の可視率はそれぞれ一度だけ適用する。

この経路では既存のShadowThreshold / ShadowSoftness / ShadowStrengthと
Roughnessを使う。ShadowStrengthはセルの明暗差を調整し、実際の遮蔽はライトの
影設定に従う。部位プロファイルのリム・ハイライト強度はToonLighting.hlsli内。
Deferredで別エンティティの設定を参照しないため、既存の個別Rim/Kawaii等の
Forward専用スタイル値を新経路に流用していない。顔SDF、髪の接線ハイライト、
学園アイドルマスター固有の照明再現は含まない。

## 最初の調整

1. マテリアルをAutoにして髪・衣装・肌の分類を確認する。判定が違うメッシュは
   既存のメッシュ分類上書きで指定する。Eye / Unlit / PBRの分類は維持する。
2. 正面斜め上に白〜少し暖色の主光源、反対側に弱めの補助光を置く。
3. 左右後方に青・マゼンタ等のスポットライトを置き、肌を主光源で読みやすく
   保ちながら、髪・衣装・輪郭に色を乗せる。光量・露出を先に調整し、Bloomは後で。
4. 輪郭幅モードはScreenPixels、幅1〜2pxから調整する。眼球や顔内部は
   メッシュ単位の無効化や幅倍率で抑える。既存の保存値は自動変更しない。
5. Extrudeから始め、必要な境界線がある場合だけTEOまたはMixを使う。

## 輪郭の処理

- ピクセル空間で押し出し方向を正規化し、縦横比・対角方向でも指定した幅にする。
- TEOの固定頂点（法線ゼロ）を押し出さず、DQS / SDEF / LBS後もゼロを保持する。
- カメラ背後・投影の特異点では画面方向への押し出しを行わない。
- 幅0・メッシュ幅倍率0の輪郭描画を省く。
- Extrudeと影パスではTEOスキニングを実行しない。
- TEO / Mixでは選択したプリセットのみスキニングし、プリセットごとに姿勢を
  キャッシュする。同じ姿勢でプリセットを変えた場合も未生成分だけ更新する。
- 使用プリセットのみ頂点バッファーを描画用に遷移し、不要なPSO復元を省く。

4種類のTEOデータは切り替え用に引き続き保持する。VRAM削減やFPS向上率を
測定した変更ではない。多灯Toonは既存のライトグリッド内のライトを個別評価し、
PBR専用の確率サンプリング／デノイズ経路は使用しない。

POMの自己影は、ToonではShadow GBufferの未使用alphaに遮蔽率として格納する。
RGBのセル陰影設定を保持し、PBRの自己影データとは分類ごとに読み分ける。
POMを持たない通常・Visibility・インポスターのToonではalpha 0が非遮蔽を表す。

## 検証

```bash
bash scripts/test-live-toon.sh
DXC=/path/to/dxc bash scripts/test-live-toon.sh --shaders
```

Windowsでは `powershell -File scripts/test-live-toon.ps1 -Shaders`。
共有HLSL計算をC++で直接実行する数値テストと、13種類のDXCコンパイルを用意した。
この実装環境でWindowsアプリ全体のMSBuild、D3D12実描画、画質比較、GPU時間は
検証できない。実機では赤青逆光、顔アップ、遠景、輪郭方式切り替えと
アニメーション停止中のプリセット切り替えを確認すること。
